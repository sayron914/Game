# Странник

Мрачное фэнтези на полосе внизу рабочего стола. Странник берёт контракты,
уходит по дороге, дерётся сам и возвращается. Игрок решает, куда его послать
и с чем.

## Структура

```
CLAUDE.md            ← начинать отсюда
docs/DECISIONS.md    что решено и почему; не переоткрывать без новых данных
docs/ROADMAP.md      этапы и точки отсечения
docs/SIM-API.md      устройство симуляции для порта на C#
docs/koncept-v2.md   ранний концепт (частично устарел, см. DECISIONS)
proto/prototype.html играбельный прототип, вся логика в классе Sim
tools/               проверки, запускаются под node
```

## Проверить прототип

```
node tools/check-all.mjs proto/prototype.html
```

Возвращает ненулевой код при предупреждениях. Сейчас проходит чисто; что
осталось нерешённым — в таблице известных дефектов в `CLAUDE.md`.

## Посмотреть, как выглядит

```
node tools/shot.mjs proto/prototype.html shot.png --dist 900 --time 0.75 --gear
```

Снимает полосу в PNG: биом задаётся шагом, время суток — от 0 (полночь) до
0.5 (полдень). Ключи `--weather rain|fog`, `--state fight`, `--mode town`,
`--bld 4`, `--wayf`. Нужен Playwright.

## Поиграть

Открыть `proto/prototype.html` в браузере. Взять контракт на доске, потратить
день-два на подготовку, нажать «В путь».

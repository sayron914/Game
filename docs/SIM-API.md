# Устройство симуляции

Карта класса `Sim` из `proto/prototype.html` для порта на C#. Класс не обращается
ни к canvas, ни к DOM — только состояние и `tick(dt)`.

## Режимы

```
mode = "town"  → время игры стоит, ход за игроком; странник ходит по лагерю
mode = "road"  → идёт вылазка, tick двигает мир
```

## Состояние странника

| поле | смысл |
|---|---|
| `str/end/skl/wil` | сила, стойкость, мастерство, воля |
| `hp / food` | здоровье и провизия |
| `dist / dir` | позиция на дороге в шагах, направление |
| `state` | `idle · walk · tele · fight · busy · decide · dead` |
| `rage / ward / swift` | накопители от триггеров, живут одну вылазку |
| `carried` | добыча при себе, банкуется только в городе |
| `who/from/why/left` | судьба: кто, откуда, зачем, что оставил дома |
| `vow` | личный обет, наследуется следующим при провале |

## Множители

Считаются функциями, а не хранятся — иначе рассинхронизируются:

```
lib()        = 1 + уровень_библиотеки × 0.05
bm(id)       = (1 + база × lib()) ^ уровень_постройки      // мультипликативно
relicMult()  = 1 + реликвии × 0.15
hpMax        = база × bm("infi") × relicMult() × hpPenalty()
```

`hpPenalty`, `atkPenalty`, `legPenalty`, `willPenalty` — от увечий.

## Триггеры

Событие → список сработавших эффектов. События: `start`, `hit`, `nth`, `kill`,
`taken`, `wound`, `grave`. Каскад важен: убийства проверяются циклом после
каждого удара, поэтому один триггер может вызвать следующий.

Ради этого бой идёт волнами 2–4 противника — на одиночном враге «вспышка по
площади» и «при убийстве — ярость» не работают.

## Цикл вылазки

```
город: взял контракт → занятия тратят дни → depart()
дорога: идёт → волны → развилки → достиг цели контракта → поворот
        предохранитель: провизии в обрез → сам поворачивает
        игрок может снять предохранитель кнопкой «рискнуть»
возврат: добыча в казну → arriveTown() → проверка контракта → новая доска
смерть: снаряжение остаётся на могиле, контракт провален, +2 дня
```

## Увечья

Возникают в бою с вероятностью `clamp(урон / hpMax × 1.6, 0, 0.30)` и
гарантированно при переходе через порог тяжёлого ранения.

Стареют в городе: ушиб проходит за 3 дня сам; необработанная рана через 4 дня с
шансом 30% превращается в заражение; заражение через 6 дней убивает.

Три способа: вылечить (дорого, дни), шина (1 день, вдвое меньше мешает, но не
заживает), не трогать.

## Сохранение

`snapshot()` / `restore()`, версия в поле `v`. **Поднимать версию при любом
изменении структуры** — иначе старый сейв загрузится в новую игру и создаст
неконсистентное состояние. Это уже случалось: игра стартовала в режиме города
без интерфейса города.

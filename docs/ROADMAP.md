# План работ

Каждый этап заканчивается точкой отсечения — проверкой, после которой проект либо
продолжается, либо закрывается. Отсечка нужна, чтобы плохие новости приходили на
второй неделе, а не на восьмом месяце.

---

## Этап 0. Окно. 1–2 недели

**Только это, без всякой игровой логики.**

Godot 4, C#. Прозрачное окно без рамки, всегда поверх остальных, высотой около
200 пикселей на всю ширину экрана, прижато к панели задач. Внутри — прямоугольник,
который едет слева направо.

Что проверить:
- окно не перехватывает клики там, где не должно (клик-сквозь)
- поведение на нескольких мониторах и при разном DPI
- корректная позиция при панели задач слева/сверху/скрытой
- поведение при запуске полноэкранного приложения
- потребление CPU при работе восемь часов подряд

Godot: `ProjectSettings` → `display/window/size/transparent` и
`display/window/per_pixel_transparency/allowed`, плюс `Window.Borderless`,
`AlwaysOnTop`, `MousePassthrough`. На Windows часть вещей может потребовать
Win32-интеропа.

**Отсечка.** Не удалось за две недели — формат нежизнеспособен, дальше нет смысла.

## Этап 1. Порт симуляции. 2–3 недели

Класс `Sim` из `proto/prototype.html` не знает ни про canvas, ни про DOM —
переносится почти дословно.

Разложить на:

```
Core/
  Sim.cs            — состояние и Tick(float dt)
  Knight.cs         — странник, характеристики, увечья
  Combat.cs         — волны, триггеры
  Town.cs           — занятия, дни, усталость
  Contracts.cs      — доска, модификаторы, слухи
  Progression.cs    — постройки, реликвии, престиж
  SaveData.cs       — сериализация
Data/
  *.json или Resource-файлы — биомы, события, контракты, увечья, снаряжение
```

Всё, что сейчас в константах — в данные. Тексты событий будут расти до сотен
строк, они не должны лежать в коде.

**Отсечка.** `Sim` гоняется из консольного проекта, аналоги `sim-headless` и
`balance-sweep` дают те же цифры, что браузерная версия.

## Этап 2. Отрисовка. 3–4 недели

Заново средствами движка, браузерный код не переносить.

- пиксельный вид: низкое внутреннее разрешение + `nearest` фильтрация,
  в прототипе делится на 2
- слоёный параллакс, привязанный к мировым координатам (не к камере — иначе
  объекты уползают, эта ошибка уже была)
- снаряжение на спрайте: общий скелет, 5 слотов, палитровый шейдер вместо
  запекания цвета в спрайт
- два режима камеры: в городе прибита к лагерю, в пути следует за странником

**Отсечка.** Человек смотрит и говорит, читается ли. Тесты этого не покажут.

## Этап 3. Баланс и содержание. 4+ недель

По списку известных дефектов из `CLAUDE.md`:

1. сделать тренировку выгодной либо убрать
2. дать деньгам применение на поздней игре
3. снизить смертность при агрессивной игре
4. довести события с 75 строк примерно до 500

Текст писать самому — тон должен быть один, это не делегируется.

**Отсечка.** Прогон `check-all` без предупреждений; человек играет неделю и
открывает игру сам, без напоминаний.
